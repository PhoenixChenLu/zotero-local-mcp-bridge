# Zotero Official References

This directory contains local reference material used to avoid guessing Zotero plugin behavior.

- `make-it-red/`: shallow clone of Zotero's official sample plugin.
- `zotero-9.0.5-server/`: selected server source files extracted from the local Zotero 9.0.5 installation.

The extracted server files are used only as local implementation references for the connector HTTP server endpoint API.

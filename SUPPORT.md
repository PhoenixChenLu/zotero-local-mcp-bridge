# Support

## Before Asking

Please include:

- Zotero version
- operating system
- plugin version
- MCP server command used
- whether you are using a clean profile or an existing profile
- the exact command or MCP tool that failed
- non-sensitive error output

Do not share auth tokens, private Zotero data, local audit logs, backup snapshots,
or screenshots that expose private library content.

## Where To Ask

- Bugs: GitHub issues after the repository is public.
- Security vulnerabilities: private GitHub security advisory.
- Usage questions: GitHub discussions or issues, depending on repository setup.

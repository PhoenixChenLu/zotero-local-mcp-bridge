# Code of Conduct

This project follows a simple contributor covenant:

- Be respectful.
- Assume good faith.
- Keep discussion technical and actionable.
- Do not post private Zotero data, local file paths, tokens, or personal data
  from another user.
- Do not use issues or discussions for harassment, spam, or unrelated promotion.

Maintainers may remove comments or close issues that violate these rules.

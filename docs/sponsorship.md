# Sponsorship

The intended sponsorship channels for this project are personal creator
channels, not a fiscal host.

## Planned Channels

- Ko-fi for international supporters.
- Afdian for Chinese-language supporters.

The repository funding file is intentionally a commented template until the
maintainer creates the real sponsorship pages. Do not publish inactive
sponsorship URLs.

## Why Not Fiscal Host

Fiscal hosts such as Open Source Collective receive money into a project budget
and pay approved expenses or invoices. That is useful for public project finance,
but it is not the current goal. The current goal is personal sponsorship that
can be paid to the maintainer's own account through each platform's payout
system.
